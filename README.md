# osu!-агент — Frame-Perfect research-полигон

Агент, который сам играет в **osu!lazer** — офлайн, на картах без рейтинга:
читает карту `.osu`, синхронизируется со звуком и ставит удары с точностью,
недостижимой для реакции человека на 60 Гц панели.

Это инженерный полигон и демонстрация: **офлайн, результаты не отправляются,
клиент игры не модифицируется, в память процесса мы не лезем** — работаем снаружи:
экран, звук, ввод.

- План проекта: [osu_plan.md](osu_plan.md)
- Статус: спайк (2–3 дня) — парсер карт, аудио-клок, проверка ввода в игру.
- Итоговая цель-демо: 10-звёздочная карта на 99%+ (см. план, §7).

Витрина (README EN/RU, LICENSE, демо) будет собрана к финальному демо.
